# Budget_DataFlow

Мінімальний Flask-застосунок для швидкого внесення доходів/витрат з телефона.
Запис одразу дописується у Google-таблицю (аркуші "Доходи" / "Витрати"),
власної бази даних немає. Розгортається на Render.

## Функціонал

- форма для внесення доходу/витрати з категоріями (з іконками) та валідацією
  суми й дати перед відправкою (дата приймає як ISO формат YYYY-MM-DD, так і
  Excel serial numbers, що дозволяє імпортувати стару дані з Excel файлів)
- **введення операцій у валюті**: перемикач ₴ / $ / € біля поля суми (форма
  внесення й редагування, доходи й витрати) — сума конвертується в гривневий
  еквівалент за останнім доступним курсом НБУ (сьогодні, або вчора, якщо
  сьогоднішній курс ще не опубліковано); якщо курс недоступний зовсім,
  операція все одно зберігається (курс приймається за 1, сума у валюті та в
  гривні збігаються), а користувач бачить попередження. За замовчуванням
  обрана гривня — конвертація вмикається лише коли явно обрано долар чи євро.
  Розбиті на категорії операції валюту не підтримують і завжди в гривні.
- необов'язкові підкатегорії з емоджі, прив'язані до однієї категорії; їх можна
  обирати при створенні та редагуванні операцій, а також додавати, перейменовувати
  й видаляти у вікні керування категоріями
- **розбиття операції на категорії** — можливість розділити одну суму між
  кількома категоріями одночасно (напр., покупка в магазині на продукти й
  побутову хімію); розбиту операцію можна редагувати, змінюючи категорії та суми
- блок "Останні записи" — топ-5 останніх доходів і витрат, з можливістю
  редагувати або видалити запис (з підтвердженням і перевіркою, що рядок
  у таблиці не змінився з моменту відкриття сторінки); розбиті операції
  розгортаються, щоб показати деталі кожної категорії
- вікно "Статистика" має два окремі режими: "По днях" — з фільтрами 7/30/90
  днів, поточного або попереднього календарного місяця та власного діапазону,
  щоденними графіками, таблицею й топ-5 категорій; "По місяцях" — з фільтрами
  пів року, рік або власний діапазон, графіком і таблицею доходів, витрат,
  чистого результату та його відсотка від доходів. В обох режимах доступний
  перегляд статистики в доларах США та євро (кнопки ₴ / $ / €), курси НБУ
  автоматично отримуються на дату кожної операції (паралельно, для швидкого
  завантаження довгих періодів)
- управління категоріями (⚙️ кнопка): додавання, видалення, редагування
  категорій для витрат та доходів, категорії зберігаються у JSON-файлі
- архівування видалених записів до окремої таблиці DELETED зі збереженням
  timestamp видалення та типу запису (доход/витрата)
- відстеження дат редагування записів (поле updated_at)
- окрема сторінка "Курси валют" (відкривається з вікна "Статистика"): перемикач
  USD / EUR (один курс за раз), фільтри періоду, графік динаміки курсу та
  підсумок — курс на початок/кінець періоду, зміна у відсотках і чи це
  девальвація, чи ревальвація гривні; курси НБУ за період підвантажуються
  одним запитом, а не по одному на кожну дату
- перемикання світлої/темної теми
- у футері сторінок показується дата й час останнього коміта репозиторію
  (останнього змерженого PR) у київському часі
- нові категорії/підкатегорії без emoji автоматично отримують підходящу emoji
  від OpenAI (потрібен OPENAI_API_KEY); без ключа чи за збою LLM категорія
  все одно зберігається, лише без emoji, з попередженням користувачу
- звіт електронною поштою (кількість операцій, сума доходів/витрат, чистий
  результат) у command-line стилі: за вчорашній день автоматично при першому
  запиті застосунку після сну процесу, або за будь-який обраний період
  вручну кнопкою 📧; надсилається через Resend (потрібен RESEND_API_KEY),
  без ключа функція просто вимкнена

## Швидкий старт

```powershell
uv sync
copy .env.example .env   # заповнити своїми значеннями
uv run python app.py
```

Відкрити `http://localhost:5000`.

## Тести

```powershell
uv run pytest
```

## Git-хук перед комітом

Хук `hooks/pre-commit` прогонює тести й скасовує коміт, якщо вони не
проходять. Увімкнути (одноразово після клонування):

```powershell
git config core.hooksPath hooks
git config core.hooksPath   # має вивести: hooks
```
